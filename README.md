# LIGHTH00K - Android APK

Official signed Android app for the LIGHTH00K private cinema.

## Latest release: 2.0.0 (V2)

Download the APK from [Releases](https://github.com/light0552/LIGHTH00KAPK/releases/latest).

- Android 8+ (`minSdk 26`), `targetSdk 34`
- `arm64-v8a` / `armeabi-v7a` / `x86_64`
- Signed with the same LIGHTH00K key as 1.0.x (installs in place)
- Brave `adblock-rust` + uBlock Origin / EasyList / EasyPrivacy
- Loads the live site at https://lighthook.netlify.app

The website updates automatically. The APK is the native shell: update it when the native theme, ad-block filters, launch flow or WebView behaviour changes.

## 2.0.0 (V2)

- Removed the standalone cat-only splash; the app now goes straight to **Loading Private Cinema**.
- The loading screen appears on every open, including a second launch from recents.
- Cat seal, warm theme and all other branding remain.
- Includes the new live RECODE web UI and the 1.0.3 playback-crash fix.

## Install

Use the APK attached to the latest release. Allow "Install unknown apps" when Android asks, then install over an older LIGHTH00K release.
